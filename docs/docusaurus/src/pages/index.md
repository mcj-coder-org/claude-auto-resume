# Claude Auto Resume

Automatic resume functionality for the Claude CLI.

- [Getting Started](/docs/intro)

## What is Claude Auto Resume?

Claude Auto Resume provides automatic session persistence for the Claude CLI, enabling
conversations to be saved and resumed after interruptions.
